# FASE B1 – SEO og lanseringssynlighet

Frontend-only. Backend, booking, admin og mail er ikke endret.

## Lagt til/oppdatert

- sitemap.xml
- robots.txt
- Canonical URL-er
- Meta titles
- Meta descriptions
- OpenGraph/Twitter metadata
- LocalBusiness schema på forsiden
- SEO-metadata på utleie-produktsider

## Test før deploy

1. Åpne index.html lokalt.
2. Sjekk at design fortsatt er riktig.
3. Åpne booking.html.
4. Test at booking fortsatt laster tjenester.
5. Åpne utleie/index.html.
6. Sjekk at utleiekort fortsatt vises riktig.
7. Etter deploy:
   - åpne /robots.txt
   - åpne /sitemap.xml
8. Test booking/admin/mail før offentlig lansering.
