Arbeidsform

Kan jobbe selvstendig eller sammen med deres folk

Oppdrag kan utføres som selvstendige småjobber eller som ekstra kapasitet sammen med bedriftens egne ansatte. Kundens utstyr kan brukes etter avtale der opplæring, tilgang og nødvendige krav er på plass.

HMS og krav

Krav avklares før oppstart

Ved arbeid på industriområde eller med kundens utstyr avklarer vi på forhånd hvilke krav som gjelder for adgang, utstyrsspesifikk opplæring, verneutstyr og arbeidsmetode.

Kompetansebevis viser gjennomført sikkerhetsopplæring. Bruk av arbeidsutstyr skjer i tillegg etter virksomhetens tillatelse og eventuell nødvendig utstyrsspesifikk opplæring.

Spørsmål og svar

Det bedriften normalt vil vite først

Kan Sørgulen Industriservice leies inn på timebasis?

Ja, for oppdrag som passer arbeidsområdet og rammene. Pris og eventuelle tillegg avklares før oppstart.

Kan du bruke utstyret vårt?

Ja, der det er avtalt og nødvendige krav, opplæring og eventuell dokumentert kompetanse er på plass.

Tar du lengre oppdrag?

Hovedfokuset er korte oppdrag som normalt kan gjennomføres innen én arbeidsdag. Større behov kan vurderes, men må avklares særskilt.

Kan vi ringe når et behov oppstår samme dag?

Ja. Tilgjengelighet varierer, men direkte telefon er den raskeste måten å avklare haste- eller ad hoc-behov.

Hva om oppgaven ikkje står på siden?

Send en kort beskrivelse. Bedriftsoppdrag varierer, og siden er ikkje ment som en uttømmende liste over alt som kan vurderes.
